A full-stack personal finance application for tracking income and expenses by category.

**Backend.** REST API in Node.js/Express over MongoDB, with JWT-based authentication and
role-based access control, and bcrypt password hashing.

**Frontend.** React 19 with Redux Toolkit for state management, TanStack Query for server
cache, Tailwind for styling, and Chart.js for spending breakdowns. Built with Vite.

**Deployment.** Deployed to AWS EC2.

**Stack:** Node.js, Express, MongoDB, JWT, React, Redux Toolkit, TanStack Query, Tailwind, Chart.js, Vite

**Source:** [github.com/liuxhy/expenses_tracker](https://github.com/liuxhy/expenses_tracker)
